# Поток машин — Traffic Dodger

A portrait Android arcade driving game inspired by the uploaded road-traffic clip.

- Endless scrolling three-lane road with moving cars and occasional vans.
- Red player car controlled with the two large left/right buttons (swipes also work).
- Collision ends the run and reveals a large ЗАНОВО button.
- Distance and best distance are saved locally.
- No network access, sign-in, ads, or special permissions.

Target device: Android 14 (including Honor X8b). Min SDK 23, target SDK 34.
