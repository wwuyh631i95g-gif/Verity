# Живой стол 1.0

Android-версия набора визуальных функций из присланного видео. Проект рассчитан на Honor X8b с Android 14 и собирается как отдельный APK через GitHub Actions.

## Что входит
- Плавающий стеклянный док поверх приложений с отдельным разрешением Android «Показывать поверх других приложений».
- Живые обои с четырьмя сезонами: снег, весенние лепестки, летние огоньки и осенние листья; есть автоматический сезон по календарю.
- Анимированный питомец-компаньон, которого можно перемещать по экрану.
- Студия обоев: выбор изображения из памяти и установка на главный экран, экран блокировки или оба.
- Домашний виджет обратного отсчёта до Нового года.
- Курсорная подборка из 11 520 процедурно сочетаемых вариантов. На Android выбранная форма работает внутри интерфейса приложения; глобально подменить системный курсор обычное приложение не может.
- Панель потребления памяти и батареи.
- Список установленных запускаемых приложений и таймер перерыва для игр. Android не позволяет стороннему приложению напрямую ставить на паузу другую игру.

## Сборка
- Android Gradle Plugin 8.7.3
- Java 17
- compileSdk 35, targetSdk 34, minSdk 26 (Android 8.0+)
- GitHub Actions собирает APK и выполняет проверку запуска на Android 14 emulator.

## Первый запуск
1. Открой приложение и выбери сезон.
2. Нажми «Установить живые обои» и подтверди установку в системном окне.
3. Для дока или плавающего питомца выдай разрешение «Показывать поверх других приложений».
4. Для новогоднего отсчёта добавь виджет «Живой стол» через меню виджетов лаунчера.
