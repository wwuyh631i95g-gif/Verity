# KeyCraft — назначение действий на кнопки громкости

Небольшое Android-приложение для быстрых действий по одиночному, двойному и долгому нажатию кнопок увеличения и уменьшения громкости.

## Действия

- Обычная регулировка громкости
- Фонарик
- Скриншот
- Камера
- Быстрые настройки
- Уведомления
- Главный экран
- Назад
- Последние приложения
- Блокировка экрана
- Разделение экрана
- Настройки
- Голосовой помощник
- Поиск
- Управление медиаплеером: воспроизведение/пауза, следующий и предыдущий трек
- Запуск выбранного установленного приложения

## Требования и ограничения

- Android 8.0 (API 26) и новее.
- Для переназначения назначенных сочетаний нужно вручную включить службу KeyCraft в разделе специальных возможностей.
- Служба запрашивает фильтрацию клавиш, но не запрашивает чтение содержимого окна и не анализирует текст на экране.
- Для действия фонарика требуется разрешение CAMERA.
- Обычные приложения Android не могут переназначать системную кнопку питания. Настраиваются только кнопки громкости.
- Система Android может разрешить фильтрацию клавиш только одной службе одновременно.

Сборка: `gradle -p KeyCraft :app:assembleDebug`.
