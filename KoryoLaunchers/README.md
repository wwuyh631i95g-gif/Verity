# Koryo Launchers

Two independent Android home-screen launchers inspired by the two North-Korean-phone interface videos provided for this project.

- **Koryo Classic**: dark navy/blue home screen, flag motif, colorful app grid and compact dock.
- **Koryo Blue**: cyan/blue tiled look and a dark quick panel with blue circular controls.

Both apps are real Android HOME activities. They list installed launcher apps, open them, support app search, show the current time/date/battery estimate, provide a wallpaper palette, and open the real Android Wi-Fi/Bluetooth/display/sound/settings pages from the quick panel. The quick-panel appearance is custom; Android itself still controls connectivity and protected system functions.

Target: Android 8+ (minSdk 26), targetSdk 34; built with Java 17 and Android Gradle Plugin 8.6.1. Intended test device: Honor X8b / Android 14.

Install both APKs, then choose one as the default Home app in Android Home-app settings. Only one launcher can be active as the default at a time; switch back there whenever needed.

These are fan-made visual recreations, not official North Korean firmware or exact replicas of a particular retail model. The uploaded clips show some interface details but do not establish every device capability or whether every screen is genuine stock firmware.
