# Сказочник (TaleBell) 0.1.0

Отдельное Android-приложение для создания и прослушивания оригинальных историй.

## Возможности
- Пользователь вставляет собственный OpenAI API-ключ.
- Текст создаётся через OpenAI Responses API; модель можно менять в поле настроек.
- Жанры: сказка, стихотворение, приключение, фантастика, юмор, басня, детектив без жестокости, спокойная история перед сном или свободный выбор нейросети.
- Длительность задаётся от 1 до 10 минут.
- Нейросети отправляется требование вернуть только художественный текст, без приветствий, пояснений, заголовков и приписок.
- Озвучка выполняется встроенным синтезом речи Android на русском языке.
- Есть ручное воспроизведение, повтор и остановка.
- Можно установить разовый или ежедневный будильник. После срабатывания приложение отправляет полноэкранное уведомление и пытается открыть экран, автоматически создать новое произведение и начать озвучку.
- API-ключ шифруется Android Keystore и сохраняется только локально; в репозиторий он не попадает.

## Важно
- В первой версии подключён OpenAI API. Нужен действующий API-ключ и доступ к API; расходы на генерацию зависят от выбранной модели и объёма текста.
- Голос создаётся системным Android Text-to-Speech, а не отдельным облачным TTS-сервисом. На телефоне должен быть установлен русский голосовой пакет.
- Android 14 может ограничивать автоматическое открытие интерфейса из фона. Для наилучшей работы будильника разреши приложению точные будильники, уведомления и полноэкранные уведомления. Если Android не разрешит открыть экран автоматически, появится уведомление, по которому можно открыть приложение.
- Для восстановления будильника после перезагрузки телефона используется RECEIVE_BOOT_COMPLETED.
- Приложение рассчитано на Android 8.0+ (API 26), с основной проверкой на Android 14 / API 34.
