# Elmore Pocket

A single Android APK containing six local mini-apps inspired by fictional Elmore web services and games:
- Elmore Plus: local profile, friends, posts, likes and optional photo attachments.
- Elmore Maps: fictional map pins and a virtual drive. It never requests GPS.
- Tweetr: local microblog feed with roleplay-style sample profiles.
- Clik-Sap: a short-video feed mock-up, including local gallery video selection.
- Kebab Fighter: a cartoon, timing-based sparkle arcade duel (no realistic fighting techniques).
- Shotofop: photo filters and local image export.

## Android support
- Minimum Android: 8.0 / API 26
- Target SDK: 28
- Tested build target: Android SDK 35, Java 17, Gradle 8.9
- No INTERNET, location, camera, microphone, contacts or storage permission is requested.
- All posts and likes are local to the app. It has no backend and does not publish to real social networks.
- Photo selection uses the Android system file picker. Edited pictures save to Pictures/Elmore Pocket on Android 10+.

This is a fan-made project. It uses original placeholder artwork and does not include episode footage or extracted cartoon assets.
