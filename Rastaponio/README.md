# Rastaponio — Android demo

The game uses the supplied road-traffic video as its background and a separate transparent shadow sprite that moves between three lanes with the left/right buttons. Collision stops the clip and offers ЗАНОВО; restarting returns the clip and player to the beginning.

- Android 14 target (API 34); min API 23.
- Portrait layout; no internet, camera, microphone, storage, or overlay permissions.
- The clip is embedded in the APK and plays silently on loop.
- Collision timing is based on the vehicle crossings visible in the supplied clip; this is a demo build and still needs testing on the target phone.

Project: standalone Rastaponio app; it does not replace Verity.
