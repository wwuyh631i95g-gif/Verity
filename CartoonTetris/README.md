# Cartoon Blocks Tetris
Original offline Android falling-block puzzle for Android 8+ (minSdk 26): expressive geometric blocks, neon board, next-piece preview, score/level/line counter, touch controls, swipes and synthesized sound effects.

The uploaded still is used only as high-level inspiration for a retro arcade board layout. This game uses newly drawn generic block faces; it does not contain copied cartoon frames, character cut-outs, names or soundtrack.
