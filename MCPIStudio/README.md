# MCPI Studio 0.1.0

Первый Android-прототип отдельного приложения с 3D-блочным миром, сенсорным управлением и встроенным редактором PiScript.

В проекте использованы идентификаторы блоков и подмножество команд API/протокола из ZIP Minecraft Pi Edition 0.1.1. Есть передвижение, обзор свайпом, прыжок, добыча и установка блоков, хотбар, локальное сохранение мира и команды world.setBlock, world.setBlocks, world.getBlock, world.getHeight, player.setTile, chat.post, checkpoint.

Технически важно: ZIP содержит Linux ARM-бинарник Minecraft Pi и API-библиотеки, но не полный исходный код движка Android. Архивная лицензия запрещает перераспространять модифицированные части бинарника. Поэтому APK — самостоятельная Android-реализация игрового мира с редактором, а не запуск оригинального бинарника Mojang. Это первая основа, не полный 1:1-порт.

Исходный проект упакован в project.tar.xz.b64; GitHub Actions собирает APK и запускает Android 14 smoke test.
